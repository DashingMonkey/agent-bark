# 快速开始

[返回首页](../README.md) · [Agent 接入](agent-integration.md) · [使用指南](usage.md)

## 安装

从 [发布页](https://gitee.com/dashingmonkey/agent-bark/releases) 下载 Windows 安装包，安装并启动 Agent Bark。需要从源码构建时，请看 [开发构建](development.md)。

## 接入第一个 Agent

1. 打开「Agents 接入」页，确认列表已检测到你使用的 Agent；刚安装的 Agent 可点击「重新扫描」。
2. 打开对应开关。Hook / 插件型显示「已接入」，本地监控型显示「监控中」。
3. 按该 Agent 的提示完成信任或重启操作，再发起一个任务。
4. 在「事件流」查看运行中会话和事件，在「悬浮窗」页启用桌面卡片。

每种 Agent 的配置路径、事件支持和排查步骤见 [Agent 接入文档](agent-integration.md)。

首次启动且尚未接入任何 Agent 时，应用会自动打开接入页。之后启动默认常驻托盘；双击托盘图标可打开主面板，关闭面板会隐藏到托盘。

## 选择提醒方式

| 需要什么 | 在哪里设置 |
| --- | --- |
| 桌面上随时查看会话 | 「悬浮窗」→ 启用 |
| 用屏幕光效感知状态 | 「通知」→ 屏幕光效，可选择显示器并预览 |
| 等待或完成时播放提示音 | 「通知」→ 声音，为各状态选择音效；默认不响 |
| 把提醒发到手机或其他应用 | 「第三方通知」→ Bark / Webhook |
| 合并重复提醒、设置免打扰 | 「设置」→ 聚合窗口 / 免打扰时段 |

提醒规则、托盘操作与悬浮窗用法见 [使用指南](usage.md)。

## 升级后

如果接入页提示 DeepSeek Harness 插件已更新，请重启正在运行的 `dsh`。磁盘上的插件更新不会替换进程已经加载的代码。

一般在界面内修改配置即可。Windows 配置文件位于 `%APPDATA%\agent-bark\config.json`，完整字段见 [配置参考](configuration.md)。
