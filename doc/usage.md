# 使用指南

## 查看任务进度

「事件流」上方展示正在运行的会话，包括项目、状态、当前任务、运行时长和工具调用次数；下方保留需要确认、等待输入、完成或失败等事件，可按类型筛选。

| 状态 | 含义 |
| --- | --- |
| 思考中 / 执行工具 | Agent 正在工作 |
| 等待确认 / 等待输入 | 需要你回到 Agent 处理 |
| 等待子代理 / 等待汇总 | 主任务仍在等待其他工作收尾 |
| 任务完成 | 收到了明确的完成信号 |
| 任务失败 | 收到了明确的失败信号 |
| 已终止 | 用户主动停止或任务被取消 |

工具调用失败不一定代表整个任务失败，Agent 可能继续重试。主动停止任务不播放完成或失败提醒。

应用每 5 分钟核验一次运行状态；托盘右键「检测运行状态」可立即触发。任务长时间没有输出、来源读取失败时，会保留最后已知状态，不直接判为失败或结束。

停滞会话可在事件流中点击「移除」。这只移除本地显示，不停止 Agent、不发送完成或失败通知；后续真实新活动仍会恢复显示。

## 桌面悬浮窗

在「悬浮窗」页启用后，卡片显示活动会话，多会话可内部滚动。多工作区时优先显示项目名，悬停查看 Agent 身份、完整工作区名和运行时长。子代理使用缩进与编号展示。

- **移动**：拖动卡片；右键「固定位置」可锁定。
- **靠边收起**：拖到屏幕顶部、左侧或右侧外缘，松手后收起；移入展开，移出收回。
- **自动展开**：停靠时遇到新会话或状态变化，会临时展开 5 秒；重复心跳和同类状态切换不会反复展开。
- **找回窗口**：单击托盘图标，让已启用的悬浮窗展开 2 秒。
- **打开面板**：双击悬浮窗，或使用它的右键菜单。

停靠位置会在重启后恢复。更细的显示与父子会话规则见 [悬浮窗配置说明](configuration.md#悬浮窗显示与靠边收起) 和 [父子任务状态](task-lifecycle.md)。

## 光效与声音

「通知」页可分别设置思考、等待、完成、失败四种状态的边缘光效、全屏特效和提示音。

- 选择单个显示器或全部显示器；边缘光效可放在顶部或四周。
- 边缘可选择流光、呼吸或关闭；全屏可选择扫描、雾散、矩阵雨或关闭。
- 使用页面上的预览按钮查看效果，点击「熄灭」结束预览。
- 内置 8 种音效，每种状态可单独选音效及播放次数（1～10 次），默认全部不响。

托盘「静音」和免打扰时段会暂停声音与第三方推送，事件仍会保留在历史中。子代理可见，但不单独触发声音、推送和全屏特效，避免并行任务频繁打扰。具体规则见 [配置参考](configuration.md#流光状态怎么来的)。

## 手机与第三方通知

「第三方通知」支持 Bark（iOS）和通用 Webhook。Webhook 可按目标服务的要求配置请求方法与消息模板，用于飞书、企业微信、钉钉、ntfy、Server酱等服务。

填写地址后可使用页面的测试按钮确认接收效果。模板可使用 `{title}`、`{body}`、`{agent}`、`{event}`、`{project}`，完整字段见 [配置参考](configuration.md#webhook-模板占位符)。

「设置」中的聚合窗口用于合并同一 Agent 的同类事件；免打扰时段支持跨零点，例如 `23:00-08:00`。

## 托盘与本地运行

双击托盘图标打开主面板，右键菜单提供显示主窗口、检测运行状态、静音和退出。关闭主面板会隐藏到托盘；开机自启在「设置」页控制。

事件接收服务仅监听 `127.0.0.1`，使用随机 token 鉴权。Hook 上报带超时，并保持退出码为 0，避免影响 Agent 本身。

应用未运行时，Hook 会将事件保存在本地 `pending.jsonl`，下次启动补投最近 1 小时内、最多 500 条事件。接入或状态排障请看 [Agent 接入与排查](agent-integration.md)。
