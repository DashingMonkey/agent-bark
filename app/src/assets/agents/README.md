# Agent 品牌图标

来源：[@lobehub/icons](https://github.com/lobehub/lobe-icons)（`@lobehub/icons-static-svg` 包，MIT License），
按文件名对应拷贝入库，便于离线使用与按需裁剪：

| trae-work.svg | trae-color（主色改为 #000000） | TraeWork |
| codebuddy.svg | codebuddy-color | CodeBuddy |
| qoder.svg | qoder-color | Qoder |

| opencode.svg | opencode（单色，currentColor） | OpenCode |
| dsh.svg | deepseek-color | DeepSeek Harness |
